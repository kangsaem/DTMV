Vector Man PC 엔진 (Windows)
==========================

사진 속 인물의 외곽선을 벡터(SVG)로 땁니다. 인터넷 없이 내 PC 에서만 동작합니다.

[실행]
1. 압축을 푼 폴더에서 VectorMan.exe 를 더블클릭합니다.
2. 처음 실행하면 Windows 보안 경고(SmartScreen)가 뜰 수 있습니다.
   → "추가 정보" → "실행" (서명하지 않은 프로그램이라 뜨는 경고입니다)
3. 검은 창(엔진)이 뜨고, 잠시 뒤 브라우저에 화면이 열립니다.
   주소: http://127.0.0.1:8765/  (내 PC 안에서만 접속됨)
4. 오른쪽 위 상태가 "PC · DirectML (GPU)" 이면 그래픽카드로, "PC · CPU" 이면 CPU 로 계산합니다.

[종료]
검은 창을 닫으면 끝납니다. 브라우저 탭은 닫아도 엔진은 켜져 있습니다.
다시 열 때 이미 켜져 있으면 화면만 새로 엽니다.

[폴더]
VectorMan.exe      실행 파일
models\            AI 모델 (BiRefNet_HR-matting, 2048). 지우면 동작하지 않습니다
_internal\         프로그램 부품
LICENSES.txt       사용한 오픈소스와 모델의 라이선스

[알아둘 점]
- 사진은 PC 밖으로 나가지 않습니다.
- 모델 학습 데이터(DIS5K)의 이용 조건 때문에 상업적 사용은 권하지 않습니다 (개인·비상업 용도).
- 설정·프리셋은 브라우저에 저장됩니다. 브라우저 데이터를 지우면 초기화되니 프리셋은 '내보내기'로 백업하세요.
